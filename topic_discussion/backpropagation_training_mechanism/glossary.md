# 反向传播与训练机制专题术语表

全教程写作遵循[术语表与中英文写作规范](../../docs/terminology.md)。本表聚焦训练机制中容易混淆的对象、边界和证据；代码标识符与结果 JSON 键名保留英文。

| 中文主称 | 英文 / 缩写 | 本专题含义 | 容易混淆之处 |
|:---|:---|:---|:---|
| 自动求导 | Autograd | 根据前向计算图组织局部反向并累积梯度 | 不等于优化器更新 |
| 向量—雅可比积 | VJP | 上游向量与局部雅可比相乘形成输入梯度 | 非标量输出调用 `backward` 时需要上游梯度 |
| 叶子张量 | leaf tensor | 由用户创建并参与求导、通常承接 `.grad` 的张量 | 中间张量默认不保留 `.grad` |
| 保存张量 | saved tensor | 反向公式需要从前向保留的状态 | 不等于所有前向激活都必须完整保存 |
| 梯度累积 | gradient accumulation | 多个微批次的梯度累加后执行一次优化器更新 | 不等于数据并行的跨 rank 梯度同步 |
| 有效批次 | effective batch | 一次参数更新实际汇总的样本或有效 token | 不能只用微批次大小表示 |
| 损失尺度 | loss scale | 为 FP16 反向放大损失与梯度，再在更新前还原 | BF16 通常不依赖同样的动态缩放 |
| 非有限梯度 | non-finite gradient | 梯度包含 `inf` 或 `nan` | 应跳过更新并调整尺度，不能继续写入参数 |
| 激活检查点 | activation checkpointing | 少保存激活，在反向时重算前向片段 | 改变计算—显存关系，不改变数学目标 |
| 激活卸载 | activation offload | 把暂不使用的保存状态搬到 host，反向前取回 | 用传输与同步换 GPU 驻留，不等于重算 |
| 峰值重叠 | peak overlap | 多类状态在同一阶段同时驻留形成显存峰值 | 参数量之和不一定等于运行峰值 |
| 正确性门槛 | correctness gate | 在比较性能前检查输出、梯度、有限值和更新语义 | 性能更快不能覆盖错误梯度 |

## 使用规则

- 首次出现使用“中文主称（English）”，后续使用中文主称或通用缩写。
- `Autograd`、`VJP`、`AMP` 可保留；普通叙述优先使用“工作负载、基线、候选、保存张量、有效更新”等中文主称。
- 前向状态、保存张量、梯度、优化器状态和工作区必须分开记录，不统称为“训练显存”。
- 不对 Notebook JSON、代码变量和框架 API 做无上下文批量替换。
