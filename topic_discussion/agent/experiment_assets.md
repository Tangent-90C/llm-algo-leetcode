# 智能体基础设施实验资产表

本表登记智能体任务复用的环境、输入契约、证据层和当前缺口。专题目前没有独立 Agent GPU Profile；模型推理由推理专题环境验证，轨迹训练由后训练环境验证，沙盒与工具环境由具体综合项目固定。缺少统一环境时，不用模拟工具或单次生成冒充端到端证据。

## 验证顺序

| 顺序 | 验证对象 | 必须固定或保存 | 进入下一步的条件 |
|:---|:---|:---|:---|
| 0 | 任务与评分 | 任务集合、初始状态、成功条件、最大步数和评测版本 | 任务可执行，评分能区分成功与失败 |
| 1 | 工具与沙盒 | 工具契约、权限、资源、超时、重置和副作用 | 相同动作能够回放并得到可解释状态 |
| 2 | 原始模型基线 | 模型版本、采样配置、完整轨迹和失败切片 | 已知主要失败来自模型行为而非环境故障 |
| 3 | 工具轨迹 SFT | 数据版本、验证结果、训练产物和冻结评测 | 工具选择、参数或观察使用得到稳定改善 |
| 4 | Agentic RL 候选 | 策略版本、采样轨迹、奖励分量、更新与恢复状态 | 在线探索带来超出 SFT 的独立任务增益 |
| 5 | 综合采用判断 | 成功率、安全、重规划、延迟、成本和回滚证据 | 形成 `accept / tune / reject` 结论 |
