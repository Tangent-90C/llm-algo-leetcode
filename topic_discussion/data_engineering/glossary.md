# 数据工程术语表

| 术语 | 本专题中的含义 | 不等同于 |
|:---|:---|:---|
| 数据身份 | 来源、版本、对象标识和许可共同形成的可追溯身份 | 文件名 |
| 数据快照 | 在给定时刻冻结、可校验的一组输入或输出对象 | 随时变化的目录 |
| 数据血缘 | 输入、处理规则、输出和消费者之间的可回查关系 | 只有一张流程图 |
| 消费者契约 | 训练、检索或评测读取数据时要求的字段与语义 | 通用格式名称 |
| 数据污染 | 训练或生成数据与独立评测样本发生直接或近似泄漏 | 所有数据重复 |
| 重复组 | 根据明确规则归为同一内容簇的一组样本 | 必然需要全部删除的样本 |
| 数据配方 | 来源、领域、长度、难度和采样权重的固定组合 | 单一数据集名称 |
| 合成数据 | 由模型、规则或工具生成，并保留生成身份与验证记录的数据 | 自动可信的数据 |
| 执行轨迹 | 工具调用、环境返回和最终回答组成的过程记录 | 只有最终文本 |
| 独立评测快照 | 与训练和候选生成隔离、版本固定的评测集合 | 从训练集临时抽样 |
| 下游对照 | 固定其他条件后，比较数据版本对训练、检索或性能的影响 | 结构校验 |
| 增量运行 | 只重算输入或规则发生变化的对象，并保留跳过依据 | 无条件跳过已有文件 |
