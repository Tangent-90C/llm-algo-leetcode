# Group 2.7: KV Cache and Serving Systems | 2.7：KV Cache 与 Serving 系统

## Learning Path | 学习路径

### Recommended Order | 推荐顺序

- KV 路径：请求状态 → `ARCH-MLA` → 22 → 37 → 24 → 34；54 的 KV Cache 量化作为压缩分支按需进入。
- Serving 路径：`INF-ITERATION-BUDGET` → 36 → `INF-CONTINUOUS-BATCHING` → 38 → `INF-SERVING-OVERLAP` → 39。
- 36 消费 37 提供的容量状态，但不管理 block 生命周期；AFD 只在 MoE Serving 和角色压力不对称时进入。
