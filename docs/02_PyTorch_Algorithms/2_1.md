# 2.1 解码器基础组件与注意力 | Decoder Components and Attention Basics

本组建立现代解码器的组件链：文本怎样变成模型状态，归一化和门控前馈网络怎样改变通道表示，位置怎样进入查询与键，以及多头注意力怎样组织查询头与 KV 头。这里先固定组件的输入、输出和状态语义；2.2 再讨论模型块、MoE 和长序列记忆结构。

## 阅读顺序

先阅读 00 建立输入状态和张量契约。01 与 02 是模型块内部两条并列通道；03 是注意力的位置前置，随后由 04 串起查询头、KV 头和历史状态。需要继续比较潜在 KV 表示时，应先进入 2.2 的 [ARCH-MLA](./ARCH-MLA_Multihead_Latent_Attention.md)，真实模型与后端证据再进入项目 71。

```text
00 输入状态
├─ 01 归一化 ─┐
├─ 02 门控 FFN ├─→ 2.2 模型块与架构分支
└─ 03 位置编码 → 04 注意力表示 ─┘
```
