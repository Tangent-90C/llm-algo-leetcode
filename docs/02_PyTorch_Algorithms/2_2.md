## 机制学习路径

- **模型块与审计：** 05 → 08。先确认残差主干和组件位置，再核对配置声明、参数身份与实际模块。
- **MoE 容量：** 05 → 06 → 07。路由器先产生候选，容量决定接纳集合，负载反馈再影响训练稳定性；多卡分发与集合通信不在本组重复展开。
- **注意力表示与访问：** 04 → ARCH-MLA；03 → 44。前一条改变保存什么状态，后一条改变历史中哪些位置可见。
- **递推与混合记忆：** 44 → 45 → ARCH-HYBRID-MEMORY。先理解有限访问范围，再比较固定状态和显式历史，最后进入层级混合。
